# Huffman Encoding/Decoding

This Python implementation constructs and uses a **Huffman Tree**, a data structure for efficient data compression. The program begins by creating a frequency table from a given text, counting the occurrences of each character. Using this table, the makeHuffman function builds the Huffman Tree by repeatedly merging the two lowest-frequency nodes into a new parent node until a single root remains. Each character is mapped to a unique binary code based on its position in the tree, with shorter codes assigned to more frequent characters.

The program supports both encoding and decoding operations. Encoding traverses the tree from a character node to the root, constructing a binary code based on the edges' weights along the path. Messages can be compressed by concatenating the binary codes of their characters. Decoding starts at the tree's root and navigates left or right based on the binary input until a leaf node is reached, revealing the original character. The program also generates hash tables for quick mapping between characters and their binary codes.

This implementation demonstrates encoding a sample message and decoding a binary string back to its original form, showcasing the efficiency and accuracy of Huffman coding. With its ability to reduce data size without loss, this solution is ideal for applications in file compression, data transmission, and storage optimization.
